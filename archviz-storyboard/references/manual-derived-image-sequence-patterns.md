# Manual-Derived Image Sequence Patterns

Use this reference when the user wants to create still images/keyframes for future architecture, real estate, loteamento, interior, location, construction, technical, or dynamic social videos inspired by training manuals or teacher examples.

Important: study only the image types, visual sequence logic, and keyframe strategy. Ignore any video-generation prompt text from the manuals. Do not copy manual prompts, instructor wording, brand marks, or course layouts.

## Core Principle

The goal is not to make prettier storyboard pages. The goal is to create useful, consistent still images that later become strong Seedance clips.

Every generated image must have one clear production job. This is a menu of possible jobs, not a requirement to use every job in every project:

- start frame;
- end frame;
- transition bridge;
- architectural reveal;
- technical explanation;
- location proof;
- material proof;
- construction progress proof;
- lifestyle proof;
- retention hook;
- final hero frame.

Start/end frames are required only when the user asks for start/end mode, chained clips, construction timelapse, loteamento progression, before/after transformation, or a transition that truly needs two controlled keyframes. For a normal storyboard, client board, moodboard, portfolio page, or simple shot plan, do not force start/end pairs.

If an image does not help the client, the portfolio, social retention, or the later video pipeline, do not include it.

The normal coherent project image set must remain intact. Do not replace the main exterior, interior, amenity, facade, room, and detail images with experimental transition images. Creative/technical images are supplemental assets selected when they improve the sales story, portfolio value, social retention, or video pipeline.

The examples in this reference are not exhaustive. Be intelligent and creative: suggest any additional image type that could make the video more professional, attention-grabbing, understandable, or commercially useful, as long as it preserves the project identity and has a clear purpose.

Every video concept must start with a strong visual hook, not merely a beautiful image. The hook can be a striking facade reveal, unexpected close-up, map/lot reveal, technical-to-photoreal transformation, rooftop/pool impact frame, construction transformation, dramatic but realistic camera angle, material macro, or another project-specific visual idea that makes viewers keep watching in the first seconds.

## Image Generation Modes

### Real Client Asset Expansion

Use this mode when the user provides real client assets such as render images, SketchUp screenshots, CAD/BIM exports, plan drawings, site plans, photos, phone photos, construction photos, drone images, or real estate sales material.

Rules:

- treat client assets as architectural truth, not loose mood references;
- classify each asset by role: geometry source, material source, room source, context/source, technical source, mood source, or construction/source;
- preserve the client's architecture, massing, openings, floor count, materials, fixed furniture, landscape, site boundaries, views, and scale;
- generate new images only as faithful extensions, safe crops, detail inserts, technical overlays, mood/material boards, or clearly labeled conceptual proposals;
- do not invent hidden rooms, facade sides, amenities, neighbors, views, pools, or floor plans from client assets unless the user asks for a conceptual expansion;
- if client fidelity matters and a needed angle is unsupported, mark the risk and ask for more references or create a conservative derived view.

For real projects, the storyboard stage should always say which generated images are strict derivatives of client references and which are creative/provisional.

### Single-Reference Derivative

Create a new keyframe from one approved image while preserving project identity.

Use for:

- safe close-up of a visible architectural/material detail;
- wider or tighter crop from the same camera family;
- nearby view only if it is visually supported by the reference;
- technical overlay over the same scene;
- mood/material overlay over the same environment;
- start or end frame for a short controlled movement.

Rules:

- preserve architecture, openings, furniture, landscape, material palette, time of day, and camera logic;
- do not invent unseen rooms, facade sides, extra floors, new furniture, or unrelated landscaping;
- if the model must infer too much, label it conceptual and ask for more references when client fidelity matters.

### Multi-Reference Composite

Blend two or more references into a new production keyframe.

Use for:

- facade render plus floor plan or technical drawing;
- room image plus moodboard/material fragments;
- aerial/site image plus lot boundary or route logic;
- masterplan plus real drone view;
- finished render plus construction phase logic;
- approved room plus visible close-up/detail reference.

Rules:

- state which reference controls geometry, which controls material, and which controls context;
- never let mood references override real project geometry;
- when sources conflict, preserve the approved project image first.

### Transformation Pair

Create two images designed to become a start/end video clip.

Useful pair types:

- raw site -> highlighted lot;
- satellite/drone view -> 3D masterplan or lot plan;
- facade photo/render -> technical line drawing;
- facade render -> exploded architectural volume;
- interior render -> material moodboard overlay;
- wide room -> close-up of one feature;
- construction stage A -> construction stage B;
- daytime hero -> blue-hour/night hero, only if the user approves time change.

Rules:

- both frames must use the same aspect ratio and compatible camera angle;
- the transformation must be understandable without a long explanation;
- preserve the same project scale, massing, boundaries, and material identity.

### Chained Start/End Sequence

Use several image pairs for a continuous or semi-continuous video.

Use for:

- construction timelapse;
- loteamento progression;
- facade-to-interior progression;
- location-to-project arrival;
- plan-to-built reveal;
- room-to-detail tour.

Rules:

- end frame N may become start frame N+1;
- label reused handoff frames as continuity frames, not repeated storyboard shots;
- keep camera height, lens feel, site boundaries, material palette, weather, and lighting coherent unless the story intentionally changes them.

### Detail Insert

Create a close-up image that keeps attention and proves quality.

Use for:

- water edge, pool, cascade, fountain, or wet stone;
- wood ceiling, stone wall, metal frame, glass track, door handle, hardware;
- countertop, sink, drawer, cabinet, appliance, joinery;
- pendant light, indirect lighting, wall wash, ceiling detail;
- fabric, cushion, upholstery, ceramic object, decorative bowl;
- vegetation, garden texture, palm/leaf movement, coastal planting;
- hand gesture, coffee, book, towel, cooking, if lifestyle is requested.

Rules:

- close-ups must be visibly related to the same project;
- keep materials tactile and real, not plastic CGI;
- avoid random luxury objects that are not in the project language.

### Technical / Explanatory Image

Create a still that explains architecture, not just atmosphere.

Use for:

- line drawing over a render;
- sketch-to-render image;
- exploded axonometric;
- stacked floor plates;
- cutaway volume;
- plan overlay;
- facade layer diagram;
- kitchen/cabinet technical drawing;
- material schedule or finish board over a real space;
- construction sequence frame.

Rules:

- use technical images only when they clarify a design or construction idea;
- keep labels short and readable;
- do not fake complex engineering details when no drawing reference exists;
- do not replace real project geometry with generic diagram geometry.

### Location / Access Image

Create images that sell where the project is and how the viewer arrives.

Use for:

- map pin over a 3D map or aerial;
- lot highlight over satellite/drone image;
- route line from city/road/beach/landmark to the property;
- phone/map interface mockup;
- road/access approach;
- neighborhood, coast, green area, water, mountain, or horizon context;
- entrance gate or arrival point as final location proof.

Rules:

- use real site references when client accuracy matters;
- do not invent geography, roads, beaches, or landmarks;
- highlight only the relevant lot/route; avoid cluttered map graphics.

### Lifestyle / Human Proof

Use people only when requested or when the sales objective benefits from them.

Use for:

- family walking in a loteamento;
- architect/client reviewing plans;
- worker on construction site;
- person using kitchen, veranda, pool, or living room;
- hand interaction with material/object.

Rules:

- architecture remains the hero;
- people must feel natural, secondary, and consistent with the project audience;
- do not add people to client-facing boards by default.

## Project-Type Playbooks

### House / Facade / Exterior

Useful stills:

1. arrival/street/garden approach;
2. facade hero;
3. facade to technical line drawing;
4. facade to exploded massing or floor-stack diagram;
5. exterior close-up: stone, wood, glass, roof, brise, pool, garden;
6. construction or worker detail if the video is about process;
7. blue-hour/night hero if the user wants an emotional closing.

Good transformations:

- exterior render -> technical drawing;
- exterior render -> exploded axonometric;
- daytime facade -> night facade;
- garden approach -> facade reveal;
- pool/detail -> full exterior hero.

### Interior Virtual Tour

Useful stills:

1. entrance or first room reveal;
2. wide living/kitchen/social area;
3. detail insert from a visible feature;
4. adjacent space or corridor transition;
5. mood/material overlay or room finish board;
6. lifestyle action if requested;
7. final window/view/emotional frame.

From one room reference, it is valid to generate 3-4 derivative images:

- hero wide;
- close-up of furniture/material/fixture;
- doorway/corridor/adjacent-space transition;
- moodboard or finish overlay;
- lifestyle detail, only when requested.

### Kitchen / Technical Interior

Useful stills:

1. kitchen hero render;
2. clean technical drawing or line overlay;
3. cabinet/drawer/storage detail;
4. countertop/sink/hardware close-up;
5. lighting/ceiling detail;
6. material board with cabinetry, stone, metal, glass, textile;
7. lifestyle/use proof if requested.

Good transformations:

- render -> technical drawing;
- technical drawing -> photoreal kitchen;
- hero kitchen -> cabinet detail;
- hero kitchen -> finish board;
- empty technical view -> furnished/styled view.

### Dynamic House Social Video

Useful stills:

1. strongest hook frame first;
2. empty site or approach;
3. drone/aerial or street approach;
4. facade hero;
5. plan/exploded diagram;
6. pool/garden/arrival close-up;
7. interior social space;
8. lifestyle or car/arrival proof if requested;
9. final hero.

Good transformations:

- site/sky/road -> house reveal;
- facade -> plan/exploded;
- exterior -> interior;
- day -> night;
- detail -> full hero.

### Location / Project Access

Useful stills:

1. city/neighborhood/landscape context;
2. aerial/satellite site reference;
3. map pin or lot highlight;
4. route/access line;
5. phone/map interface;
6. road/arrival view;
7. project gate/facade/entrance.

Good transformations:

- map pin -> lot highlight;
- aerial -> route line;
- road -> arrival gate;
- phone map -> real project view.

### Loteamento / Development

Useful stills:

1. raw land or aerial;
2. lot boundary highlight;
3. masterplan overlay;
4. roads and infrastructure;
5. green areas, water, amenities, landscape;
6. entrance gate;
7. human/community lifestyle;
8. daytime masterplan/hero;
9. night/blue-hour entrance, only if requested.

Good transformations:

- raw terrain -> highlighted parcel;
- highlighted parcel -> masterplan;
- masterplan -> infrastructure/roads;
- infrastructure -> landscaped community;
- community -> lifestyle/family;
- gate day -> gate night.

### Construction Timelapse

Use this only when the user requests construction/timelapse/process videos.

Recommended image chain:

1. existing site or raw land;
2. earthwork and site preparation;
3. foundations/slab;
4. columns/beams/structure;
5. masonry/walls/envelope;
6. roof/framing/glazing;
7. facade and exterior finishes;
8. interiors and fixed furniture;
9. pool/landscape/external works;
10. completed project daytime;
11. final emotional hero, such as blue hour, if requested.

Rules:

- keep the same camera family and site boundaries across the chain;
- show realistic construction logic, not impossible instant morphs;
- include workers/machinery only if they support the stage and scale;
- avoid fake unsafe construction scenes or random equipment.

## Sequence Selection Rules

1. Ask what video type the user wants only if it is unclear: facade/interior, location, loteamento, timelapse, technical drawing, dynamic house, mood overlay, or custom transition.
2. For normal real estate videos, use mostly photoreal project stills plus a few detail inserts.
3. For high-retention social videos, add one or two creative transformation pairs, but keep the project readable.
4. For client/portfolio deliverables, prioritize moodboards, finish boards, technical detail boards, and polished stills.
5. For Seedance production, prioritize clean keyframes, start/end pairs, shot order, and continuity notes.
6. Do not create all possible image types in one package. Select the few that fit the goal.
7. If the user says they will later ask for these creative video types, store the logic but do not generate those images immediately.

## Output Template

When planning images before generation, return a compact table:

```markdown
| Image | Type | Source References | Generation Mode | Production Job | Consistency Anchors | Risk |
|---|---|---|---|---|---|---|
| 01 | Facade hero | approved-facade.png | single reference | opening hook | massing, roof, stone, landscape | low |
| 02 | Facade to exploded volume | approved-facade.png + plan.pdf | multi-reference transformation | technical reveal | same facade, same floor count | medium |
```

Then write one English GPT Image prompt per still/keyframe.

For start/end pairs, label:

```text
PAIR 01
START FRAME:
END FRAME:
CONTINUITY LOCKS:
SEEDANCE USE:
```

## Prompting Requirements

Every still/keyframe prompt must include:

- selected aspect ratio;
- exact reference filenames and roles;
- what must remain identical;
- what is allowed to change;
- image purpose in the sequence;
- photoreal architectural target;
- negative constraints against changed geometry, random objects, extra people, fake text, logos, watermarks, and distorted materials.

Do not ask the image model to create the final video. Generate clean stills/keyframes first, then create Seedance prompts only after the stills/keyframes are approved.
