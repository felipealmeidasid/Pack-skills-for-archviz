# Video Style Profiles

Use this reference when the user asks for a video style, wants to use previous reference videos, asks for a style preset, or describes a new style for an archviz, real estate, construction, interior, resort, loteamento, location, or sales video.

These profiles are not limits. They are reusable style ingredients. The user may request a new style at any time, combine multiple profiles, or provide new reference videos to expand this file later.

## Open Style System

Do not force every video into one profile. Most finished videos mix multiple profiles:

- a technical overlay intro can become a lifestyle walkthrough;
- a location reel can become a lot-marking video;
- a presenter-led video can include construction comparison;
- a resort film can include drone, lifestyle, food, kids, spa, and brand closing;
- a facade launch can include technical studies, luxury reveals, and sales copy.

When several styles apply, name the blend:

```text
Style blend: Technical Overlay Sales Reel + Presenter-Led Archviz Tour + Luxury Facade Launch.
```

Then define which profile controls each part of the story:

```text
00:00-00:03: Technical Overlay hook.
00:03-00:08: Luxury Facade reveal.
00:08-00:15: Lifestyle proof with character.
00:15-00:20: Sales close.
```

## Storytelling Rule

The final edited video must tell a story. Never assemble random camera moves over random rooms, facades, or amenities.

Every video needs:

- a visual hook in the first 3 seconds;
- a clear promise, question, transformation, reveal, or emotional reason to keep watching;
- progression from problem, potential, location, design logic, transformation, lifestyle, value, or final reveal;
- continuity anchors across shots, such as material, light, line, water, facade rhythm, floor plan logic, character action, or site movement;
- a closing beat that leaves the client impressed, informed, or imagining themselves in the property.

For real estate and archviz, the story should help the viewer imagine:

- arriving at the place;
- understanding the project;
- moving through the environment;
- touching or seeing materials up close;
- using the spaces;
- living, investing, vacationing, hosting, buying, or presenting the project.

## First 3 Seconds Retention Rule

The first 3 seconds must be visually stronger than the rest of the video. Use a hook that creates immediate curiosity or impact.

Good hooks:

- impossible-to-ignore transformation: empty lot to finished house, technical drawing to render, raw space to furnished room;
- high-value claim: exclusive, premium, beachfront, limited lots, investment potential, delivery speed;
- visual question: before/after, which construction system is better, where is this project located;
- dramatic movement: drone descent, crash zoom, snap zoom, fast push-in, whip pan, falling 3D text, neon line trace, hologram reveal;
- tactile closeup: hand touching stone, waterline glide, faucet, wood, curtain, concrete, fabric;
- presenter hook: character addresses the camera or gestures toward the reveal;
- cinematic opening: sunrise aerial, luxury car arrival, resort masterplan, window/airplane location reveal.

Avoid slow, generic, low-information openings unless the user explicitly wants a calm institutional film.

## Timing For Seedance 2.0

Use Seedance prompts to reduce CapCut dependency when possible.

- 1-2 seconds: fast feature flash, material insert, match cut, technical callout, quick social beat.
- 1.5-3 seconds: default normal shot for social videos, including facade details, room reveals, amenities, and close-ups.
- 3 seconds: hook, impact, snap reveal, falling text, quick comparison, fast transformation beat.
- 4-5 seconds: complex transformations, technical-to-real morphs, construction progressions, character lifestyle actions, room-to-room reveals, or shots that need more time to read.
- 6-8 seconds: use sparingly, only for unusually complex walkthroughs or calm premium campaign moments outside fast social pacing.
- 10 seconds: avoid for social storyboards unless the user explicitly wants a slow hero scene, resort ambience, full opening, or closing sequence.

Do not ask one Seedance clip to do too many unrelated actions. Break the story into clips, each with one clear action and one clear visual purpose.

For a 30-second social video, prefer 8-14 shots. Do not default to six 5-second scenes unless the user asks for a slower premium film.

## Profile Template

Each profile below follows this structure:

- Use when;
- Story shape;
- Hook ideas;
- Camera and motion;
- Transitions;
- Sound design;
- Seedance timing;
- Prompt phrases.

## 1. Luxury Facade Launch

Use when: launching or presenting a premium house, tower, facade, condominium, or high-end residence.

Story shape:

- start with a strong facade, exclusive claim, number, gate, car, or architectural detail;
- reveal the massing, material palette, lighting, and access;
- show technical proof or premium features;
- land on a lifestyle or final hero frame.

Hook ideas:

- giant premium/exclusive text above the facade;
- snap zoom into facade lighting or entrance;
- low car arrival into porte-cochere;
- night lighting turns on across the facade;
- technical overlay appears over the facade in the first 3 seconds.

Camera and motion:

- slow push-in;
- arc right or arc left;
- lateral truck with landscape parallax;
- low glide near pool or driveway;
- tilt up from material to roofline;
- drone approach from the same visible angle.

Transitions:

- architectural line match cut;
- light sweep;
- object wipe using vegetation, columns, walls, car, or mullions;
- hard cut with low sound hit for sales beats.

Sound design:

- low sub hit on facade reveal;
- soft whoosh for glides;
- glass shimmer for windows;
- subtle luxury music bed.

Seedance timing:

- 3 seconds for opening hook;
- 5 seconds per facade move;
- 6-8 seconds for technical overlay transformation.

Prompt phrases:

```text
Open with a high-impact facade reveal in the first 3 seconds, using a fast push-in that settles into a premium slow glide.
Keep the architecture exact while lighting accents turn on across the facade.
Use a low, luxury car-arrival angle without blocking the entrance geometry.
```

## 2. Technical Overlay Sales Reel

Use when: explaining design value, solar study, natural light, thermal comfort, acoustic comfort, automation, structure, circulation, material systems, or smart-home features.

Story shape:

- begin with a bold technical question or claim;
- show the project with holographic overlays;
- explain 2-4 benefits visually;
- return to the real architecture and close with value.

Hook ideas:

- facade freezes and technical overlays ignite over it;
- heat map or solar arc appears instantly;
- split comparison before/after;
- blueprint grid locks onto the building;
- text asks a sales question.

Camera and motion:

- static or slow push-in while overlays animate;
- arc across facade with locked technical annotations;
- top-down plan-to-render transition;
- zoom from detail into technical diagram;
- tilt from ground/pool to solar path.

Transitions:

- blueprint-to-render dissolve;
- line match cut;
- hologram flicker;
- light sweep;
- hard cut on text or data point.

Sound design:

- digital shimmer;
- soft mechanical clicks;
- low hit when an overlay locks;
- clean whoosh for diagram transitions.

Seedance timing:

- 3-4 seconds for one technical hook;
- 5 seconds for one feature;
- 8 seconds for complex technical-to-real transformation.

Prompt phrases:

```text
Technical annotations appear as clean holographic overlays locked precisely to the facade geometry.
The camera remains stable while solar arcs, airflow lines, and material callouts animate without changing the architecture.
The overlay fades out and the real facade returns as the hero image.
```

## 3. Technical Drawing To Real Architecture

Use when: showing design process, CAD drawing, sketch, moodboard, floor plan, exploded axonometric, BIM, construction logic, or design authority.

Story shape:

- begin with drawing, board, plan, or model;
- reveal design logic;
- transition from technical representation to realistic architecture;
- finish with a render, site, construction, or lifestyle proof.

Hook ideas:

- extreme zoom through a technical drawing;
- sketch gains materials and light;
- exploded model assembles;
- furniture pieces fly into position;
- CAD lines become a finished room.

Camera and motion:

- extreme zoom in/out;
- slow dolly out from drawing board;
- arc around exploded model;
- top-down to facade;
- static camera while parts assemble.

Transitions:

- drawing-to-render morph;
- texture fade-in;
- blueprint line wipe;
- object assembly;
- technical board zoom-out.

Sound design:

- paper/pen foley;
- mechanical clicks;
- shimmer as materials appear;
- low rise into final render.

Seedance timing:

- 6-8 seconds for technical-to-real transformations;
- 5 seconds for model assembly;
- 3 seconds for quick diagram hook.

Prompt phrases:

```text
The technical line drawing gradually gains realistic materials, shadows, glass, wood, and landscaping until it becomes the final architectural scene.
Exploded architectural components slide into place with mechanical precision while the camera performs a slow arc.
```

## 4. Location And Arrival Reel

Story shape:

- start with map, pin, airplane, aerial, or city question;
- zoom out or descend into the region;
- mark the exact lot or building;
- show arrival, facade, car, or lifestyle destination.

Hook ideas:

- red map pin lands on the property;
- extreme zoom from map to real aerial;
- airplane window reveals city and project marker;
- neon perimeter traces the site;
- luxury car arrives at the property.

Camera and motion:

- drone descent;
- extreme zoom out or zoom in;
- top-down lot view;
- arc right around marker;
- low car-following shot;
- airplane window push-through.

Transitions:

- map-to-aerial morph;
- cloud wipe;
- pin impact with dust;
- neon trace;
- road line match cut.

Sound design:

- airy riser;
- pin impact hit;
- wind bed;
- engine pass-by;
- digital map pulse.

Seedance timing:

- 3 seconds for pin/map hook;
- 5 seconds for drone descent;
- 6-8 seconds for map-to-real transition.

Prompt phrases:

```text
Open with a fast location hook: a red location marker drops onto the exact lot and releases a subtle dust impact.
The camera descends smoothly from a high aerial view toward the property, preserving real-world proportions.
```

## 5. Lot Marking And Development

Use when: presenting a lote, land sale, subdivision, corner lot, marked perimeter, project insertion, construction potential, or before/after development.

Story shape:

- establish the site and surrounding value;
- mark the lot precisely;
- show size or key sales data;
- reveal construction or finished project;
- close with lifestyle or investment value.

Hook ideas:

- neon line traces the lot perimeter;
- 3D square-meter text drops onto the terrain;
- empty lot transforms into finished house;
- construction timelapse starts instantly;
- drone descends from ocean/city into the lot.

Camera and motion:

- top-down;
- drone descent;
- slow forward aerial push;
- static camera while neon traces;
- timelapse construction from same angle;
- pull-out to finished project.

Transitions:

- neon trace;
- dust impact;
- construction timelapse;
- before/after match cut;
- lot boundary wipe.

Sound design:

- electric neon buzz;
- dust impact;
- construction foley;
- low boom on finished reveal.

Seedance timing:

- 3-4 seconds for perimeter hook;
- 5 seconds for one marked-lot shot;
- 6-8 seconds for construction progression.

Prompt phrases:

```text
A clean light blue neon contour traces the exact lot perimeter while the camera slowly descends.
Large grounded 3D text displays the lot area, integrated into the terrain with realistic shadows and dust.
The empty lot transforms into a finished luxury house while all surroundings remain unchanged.
```

## 6. Construction Timelapse And Comparison

Use when: showing construction system, steel frame vs masonry, obra concluida, price, delivery time, building process, or education + sales.

Story shape:

- open with a question or comparison;
- show the raw lot/site;
- demonstrate stages of construction;
- compare benefits or systems;
- close with finished facade and sales proof.

Hook ideas:

- "Which is the better choice?" split-screen;
- construction system appears over facade;
- demolition/empty-lot impact;
- structure rises quickly;
- "obra concluida" stamp lands.

Camera and motion:

- static facade comparison;
- aerial or elevated construction timelapse;
- push-in toward structure;
- crane up as building assembles;
- hard cuts between systems.

Transitions:

- split-screen wipe;
- dust burst;
- structure assembly;
- speed ramp;
- text stamp.

Sound design:

- construction hits;
- metallic clicks;
- deep impact for completion stamp;
- fast risers for system comparison.

Seedance timing:

- 3 seconds for comparison hook;
- 5 seconds per construction stage;
- 6-8 seconds for full build progression.

Prompt phrases:

```text
Open with a bold construction comparison hook in the first 3 seconds.
Show a fast but readable timelapse of the structure assembling from the same camera angle.
End on the completed facade with sales text space reserved for editing.
```

## 7. Interior Material Transformation

Hook ideas:

- unfinished room turns into finished kitchen;
- faucet/stone/wood closeup starts the video;
- hand touches material and the room transforms;
- CAD/moodboard becomes the real interior;

Camera and motion:

- slow push-in;
- slider move across material;

Transitions:

Sound design:

Seedance timing:

- 6-8 seconds for raw-to-finished transformation.

Prompt phrases:

```text
Begin on a tactile closeup of the stone countertop, then pull back into the full kitchen reveal.

```

## 8. Virtual Walkthrough

Use when: simulating a visit through rooms, amenities, a house, apartment, hotel unit, or sales tour.

Story shape:

- start with the strongest room or entrance hook;
- move through connected spaces logically;
- use details to bridge rooms;
- include lifestyle only where it helps the viewer imagine use;
- finish with view, suite, pool, office, balcony, or emotional closing.

Hook ideas:

- fast entrance-to-living reveal;
- doorway portal into the main space;
- pool reflection appears before interior;
- camera moves through a glass door;
- character opens curtain to reveal view.

Camera and motion:

- walkthrough glide;
- threshold reveal;
- path trace;
- slow push-in;
- lateral truck;
- doorway portal cut.

Transitions:

- doorway portal cut;
- object wipe;
- window/mullion wipe;
- texture match cut;
- curtain reveal.

Sound design:

- soft footstep/room tone;
- gentle whoosh;
- curtain fabric foley;
- ambient home sounds.

Seedance timing:

- 5 seconds for one room;
- 6-8 seconds for room-to-room transition;
- split longer tours into separate clips.

Prompt phrases:

```text
The camera glides forward as if the viewer is walking through the home, moving from the living room toward the kitchen with a clean threshold reveal.
Keep the room layout, furniture positions, windows, lighting, and materials consistent with the reference.
```

## 9. Character Lifestyle Routine

Use when: showing residents living in the space, morning routine, cooking, training, working, relaxing, family use, or aspirational daily life.

Story shape:

- start with a relatable action;
- move through a routine that proves the home's value;
- show interactions with key spaces and materials;
- end with comfort, view, family, work, wellness, or hosting.

Hook ideas:

- alarm clock or morning light;
- hand opens curtain;
- character starts treadmill with view;
- person prepares coffee or food;
- closeup of hand touching a premium material.

Camera and motion:

- medium character shot;
- slow push-in;
- detail insert;
- profile tracking;
- handheld-like smooth glide;
- rack focus from character to space.

Transitions:

- action match cut;
- object wipe;
- texture cut;
- doorway cut;
- L-cut/J-cut with lifestyle sound.

Sound design:

- room tone;
- coffee, water, fabric, steps;
- soft whoosh;
- warm music bed.

Seedance timing:

- 5 seconds for one simple lifestyle action;
- 6-8 seconds for a complete action like opening curtain or preparing food.

Prompt phrases:

```text
Use the character sheet as the exact identity reference. The character performs one simple lifestyle action that supports the architecture.
The person remains secondary and never blocks the key room layout, furniture, windows, or material details.
```

## 10. Presenter-Led Archviz Tour

Use when: a presenter, architect, broker, host, designer, or brand representative explains the property or guides the viewer.

Story shape:

- presenter hook in first 3 seconds;
- presenter introduces the promise or key value;
- camera cuts to architecture, details, and overlays;
- presenter returns for proof or closing;
- final shot lands on project or brand.

Hook ideas:

- presenter points toward the reveal;
- presenter stands in front of a view or facade;
- presenter opens door;
- presenter touches material and explains value;
- presenter holds plans or a model.

Camera and motion:

- medium presenter shot;
- push-in while presenter talks;
- cutaway to material detail;
- lateral track past presenter into architecture;
- rack focus from presenter to facade.

Transitions:

- cut on gesture;
- object wipe with plans/model;
- J-cut from voice to next shot;
- match cut from plan to real space.

Sound design:

- clean voice presence;
- subtle whoosh on cutaways;
- low hit on hero reveal;
- room ambience.

Seedance timing:

- 3-5 seconds for presenter hook;
- 5 seconds for one gesture/action;
- keep speech implied unless generating final video with synced voice is supported.

Prompt phrases:

```text
Use the presenter character sheet as the exact identity reference. The presenter calmly gestures toward the facade, then steps aside so the architecture becomes the hero.
```

## Building A Custom Style

When the user describes a new style, do not reject it because it is outside these profiles. Build a custom style profile using:

- reference mood;
- project type;
- audience;
- hook;
- story arc;
- camera vocabulary;
- transition vocabulary;
- sound design;
- clip timing;
- what to avoid;
- prompt phrases.

Then state whether it should become a new saved profile later.

## Style Blend Output

When selecting a style for a project, write:

```text
Selected style blend:
- Primary: Luxury Facade Launch
- Secondary: Technical Overlay Sales Reel
- Accent: Character Lifestyle Routine

Story promise:
In the first 3 seconds, prove this is a premium, intelligent house; then reveal how the architecture works and why the viewer can imagine living there.

Retention hook:
Fast facade push-in with technical overlays igniting across the building, landing on the real night-lit facade.
```

## Global Negative Constraints

Avoid:

- random room montage without story;
- camera moves that do not reveal new information;
- overusing technical overlays until the architecture disappears;
- adding people without references or user request;
- long slow openings for social videos;
- unsupported reverse angles;
- changing architecture, materials, room layout, site context, or facade geometry;
- too many actions in one Seedance clip;
- text clutter inside storyboard frames.
