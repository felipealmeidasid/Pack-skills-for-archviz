# Reference Library

Use this file as the entry point for the real architecture reference library.

The reference library is a style-intelligence layer. It stores curated links, style rules, architect/studio research anchors, prompt language, and guardrails so the skill can create more realistic real estate worlds without copying any specific project.

## Read Order

When a user asks to use real references, Pinterest, Behance, architects, studios, moodboards, screenshots, or architectural styles:

1. Read `reference-library/00-index/usage-rules.md`.
2. Read `reference-library/00-index/master-index.md`.
3. Read `reference-library/00-index/style-taxonomy.md`.
4. If architect/studio grounding matters, read `reference-library/00-index/architects-and-studios.md`.
5. If Pinterest appears in the request, read `reference-library/00-index/pinterest-discovery-boards.md`.
6. Load only the matching style folder under `reference-library/01-styles/`.

## Supporting Sections

- `reference-library/02-building-elements/` stores references by component, such as facades, lobbies, rooftops, pools, balconies, interiors, and landscaping.
- `reference-library/03-materials/` stores material behavior and prompt vocabulary.
- `reference-library/templates/` stores templates for new reference cards and new style folders.

## Usage Rule

Use references to extract broad architectural grammar: massing, proportions, material behavior, climate logic, light, landscape, camera language, and realism constraints.

Do not copy or closely reproduce a specific project, facade, floor plan, image composition, proprietary detail, furniture arrangement, project name, or authored design identity.
