# Building Elements Index

Use this section when a project needs references by component instead of by style.

Suggested subfolders:

- `fachadas/`
- `lobbies/`
- `rooftops/`
- `piscinas/`
- `spas-wellness/`
- `varandas/`
- `interiores/`
- `paisagismo/`

Each element folder should store reference cards focused on function, not style. Example: a rooftop pool reference can support both vertical urban premium and resort residential worlds.
