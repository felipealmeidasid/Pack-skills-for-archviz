# Style Folder Template

Create one folder per style under `01-styles/`.

Required files:

- `style-brief.md`: essence, architecture, materials, landscape, light, human behavior, best uses.
- `project-links.md`: verified project/reference cards.
- `architects.md`: architects/studios as research anchors, not copy targets.
- `prompt-rules.md`: words, skeleton prompts, continuity anchors.
- `avoid.md`: cliches, realism failures, copyright/identity boundaries.

Optional files:

- `pinterest-discovery.md`: boards or pins used only for discovery.
- `materials.md`: material palette and material behavior.
- `camera-language.md`: lens, framing, movement, still/video tendencies.
- `scene-library.md`: repeated scenes for that style.
