# Usage Rules

## Legal And Creative Boundaries

Use references as inspiration and analysis material. Do not copy, clone, or closely reproduce any individual project, image, facade, composition, furniture arrangement, proprietary detail, or brand identity.

Extract broad architectural language, climate responses, material relationships, light strategies, common camera patterns, scene functions, and realism guardrails.

Avoid: "in the exact style of this project", "copy this facade", "same composition as this Behance image", "make a clone of this architect's house", or using one project as the sole reference for a full generated world.

## How To Use Pinterest

Pinterest is best for discovery and clustering, not final attribution.

1. Open the pin when possible.
2. Try to identify the original project source.
3. Prefer saving the original source link in `project-links.md`.
4. If only the Pinterest board is available, label it as "discovery board" and do not treat it as a verified project.

## How To Use Behance

Behance is useful for archviz, real estate visualization, mood, material rendering, and camera language.

1. Record the project title, creator, location if available, and link.
2. Note whether it is real built architecture, conceptual design, or archviz exercise.
3. Extract only general rules.
4. Avoid copying exact image layouts, names, or unique authored designs.

## Confidence Fields

Use these values consistently:

- `Source type`: official-studio-page, architecture-publication, behance-project, pinterest-discovery-board, user-uploaded-reference, unknown.
- `Verification status`: verified-source, creator-page, publication-page, discovery-only, unverified.
- `Rights status`: reference-only unless the user owns the content or a license is explicit.
- `Original source found`: yes, no, partial, not-needed.
- `Copy risk`: low, medium, high.

High copy risk means the reference has a very distinctive facade, plan, image composition, product identity, or authored design signature. Use it only to extract broad rules.

## Quality Threshold

Add a reference only if it teaches at least one clear rule about architecture, materials, light, camera, climate, real estate storytelling, or believable human use.
