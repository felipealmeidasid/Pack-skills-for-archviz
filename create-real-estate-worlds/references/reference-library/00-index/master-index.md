# Reference Library Master Index

This library stores curated real-world references for creating cinematic real estate worlds. It is a style-intelligence layer, not an image-scraping dataset.

Use it to extract architectural grammar: massing and proportions, material hierarchies, climate logic, light behavior, landscape integration, camera language, lifestyle cues, realism constraints, prompts, and negative prompts.

Do not copy or reproduce a specific project, facade, image composition, floor plan, proprietary detail, or authored design. Use references to understand patterns and constraints.

## Suggested Workflow

1. Read `usage-rules.md`.
2. Read `style-taxonomy.md` to choose the right style.
3. Read the selected style folder: `style-brief.md`, `project-links.md`, `architects.md`, `prompt-rules.md`, and `avoid.md`.
4. Extract rules, not images.
5. Generate prompts that cite the style library as inspiration but do not copy individual works.

## Good Reference Sources

Prefer official architect/studio websites, Behance project pages with clear authorship, ArchDaily or architecture publications for built projects, and Pinterest boards only as discovery maps. Trace Pinterest pins back to original sources whenever possible.
